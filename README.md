# CMOS Logic Gates Design - Microwind

This repository contains the layout designs and simulations for fundamental digital logic gates, designed and verified using the **Microwind** EDA tool. The project covers basic, universal, and exclusive logic gates implemented at the transistor level using CMOS technology.

## 📂 Repository Structure

The project is organized into individual folders for each logic gate under the main `Basic Gates` directory:

```text
Basic Gates/
├── AND/
├── NAND/
├── NOR/
├── NOT/
├── OR/
├── XNOR/
└── XOR/
